# 🔗 سدّ فجوة «بطاقة بلا أمر»: ما أرسله الديمو ولماذا غاب عن MT5

## فحص الكود الحي — ماذا أرسل الديمو؟
بطاقات الإشارة (ماركت/معلقة) تُرسل لحظة القرار في التحليل، ثم يُفترض أن
يلتقطها الـ tick manager ويضعها. وجدت ثلاث حالات انفصال:

1) **ماركت قديمة >60 دقيقة عند أول رؤية** (مثلاً بعد ريستارت): بوابة
   منع-البعث كانت تتجاهلها صامتة للأبد ⇒ بطاقة وصلت ولا أمر قط. ← أُصلح:
   أي صف OPEN لم يُنفَّذ قط (بلا ticket وبلا close_price) يُوضع دائماً مهما
   عمره؛ الحماية تبقى فقط للصفوف المنتهية (لها close_price/ticket).
2) معلقة أُلغيت بعد فشل إعادة التفويض (قاعدة 3 وكلاء) ⇒ إلغاء مقصود
   (بطاقة الإلغاء الحالية نصها مضلل — عرضتُ تحسين نصها سابقاً).
3) منفّذ ميت ⇒ watchdog يحييه (موجود).

## الاختبارات
- صف منتهٍ (close_price) لا يُبعث أبداً حتى لو بقيت حالته OPEN.
- صف OPEN قديم لم يُنفَّذ قط ⇒ يُوضع MARKET رغم عمره.
